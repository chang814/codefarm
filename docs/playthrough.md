# 通关测试与范本（0.2.2）

这份文档记录 0.2.2 的整局通关测试：走了哪条路线、每一档花了多少游戏时间、测试中发现并修掉的问题，以及相邻两份范本之间多了什么。

0.2.7：未熟草重置为 400 tick 幼苗，成功与失败收割均花 action_ticks()。真实玩家路线包含停止盲收、等待后单次收割来攒够条件费用。最新验收见 [review-0.2.7.md](review-0.2.7.md)。

0.2.6 历史复验（收割规则已被 0.2.7 替代）：147 项路线检查、45 次购买、3112.74 秒游戏时间通过。失败收获改为固定 400 tick；同一起点各运行 30 秒，speed 盲收 20 干草、iff 条件循环 30 干草。原表为 0.2.2 历史结果，当时收获规则与 Windows 验收见 [review-0.2.6.md](review-0.2.6.md)。

## 怎么跑

```bash
cmake -S . -B build-tests -G Ninja -DCODEFARM_BUILD_EXTENSION=OFF
cmake --build build-tests
./build-tests/codefarm_tests          # 含 test_full_playthrough 与 test_every_node_has_exemplar
./build-tests/codefarm_playthrough    # 打印逐档路线、用时和每次购买时的背包
```

- 路线代码在 `tests/playthrough_route.hpp`。
- 玩家模型在 `tests/playthrough.hpp`。
- 单元测试入口在 `tests/test_playthrough.inc`。

## 规则

- **起点。** 测试从全新存档出发，种子 20261111。
- **只用玩家操作。**
  - 在技能树按当前余额 `unlock`。
  - 在编辑器里放入一段程序，再点「运行」。
  - 无头快进游戏时间。
  - 不调用 `grant_for_test`，也不往背包里加东西。
- **每一档运行的就是该技能的范本。** 范本是 `game/exemplars/<id>.cpp`，有头文件时还有 `<id>.<文件名>`。游戏的提示窗口和技能详情读的是同一份文件。
- **买技能之前先确认它被锁住。** 用这项技能的范本必须报「尚未解锁」，然后才去买。
- **每一档都要验证「先痛后药」。** 先测出旧程序的不足（痛），再测出新程序把它解决了（药）。

## 发现并修掉的问题

### 卡关与成本

- **原地 while 和走一行一样慢。** 移动现在只花半个动作（`World::move_ticks()`）。走一行收割从 1.00 提到 1.33 干草/秒，买「移动」才划算。
- **买了胡萝卜后木头净收入为 0，加速 2 和树木之前卡死。** 胡萝卜改为只花干草。
- **刚买完技能后的第一刀被算成「1× 下也会空挥」。** 那一刀其实是购买后重新开始的第一刀；验证改为跳过第一刀。
- **后半程胡萝卜不够。** 路线里补买胡萝卜 2、3 级。玩家模型会在胡萝卜低于 30 时切回分文件范本补到 150。

### 模拟器

- 仙人掌排序和成片判断跨边缘环绕，导致整片永远不算排好。改为不环绕。
- 田种满时恐龙苹果没有落点，一局只能得 1 根骨头。现在会退到任何不是身体的格子，一局得 121 根。
- 枯萎南瓜一直占着格子。现在收割它会清掉。
- 上一次运行留下的迷宫会把后面的程序围住。现在新运行开始时结束迷宫。
- 树和迷宫之后空着的草地一直是空的。现在会重新长草。

### 解释器

- 实数支持 `+ - * /` 和负号。
- 支持二维数组参数 `int a[N][M]`，它与调用方共享同一个数组。
- 文件级 `const` 对函数和无人机都可见。
- 解锁名不区分大小写，`unlock(Pumpkins)` 能识别。
- `get_time()` 只能在解锁「计时」后使用，以前「打印」也能用。
- 变量未解锁时把 `for` 的 `i` 写进判断，会给出清楚提示。
- 早先修过的：
  - 函数调用改为按帧执行。
  - `if` 里的 `break` / `continue` 可用。
  - 比较折叠。
  - 下标只求值一次。
  - `for` 支持 `<=` 和起始表达式。
  - 支持叠写的 `case`。
  - 支持带类型的变量、初始化列表和常量数组。
  - 修了事件增长和 `wait_for` 重试。
  - 修了结构体别名和动态作用域。
  - 修了 `num_drones` 计数。

### 范本本身

- 向日葵、数组和南瓜范本会先清掉别的作物，再种自己的。
- 仙人掌范本循环到种下为止。
- 向日葵范本检查 `m.ok`。

## 范本逐步递进

### 怎么保证一步只多一个概念

- **同一份文件。** 范本 `game/exemplars/` 就是通关测试实际运行的程序。测试和游戏读同一份文件，不存在另写一份「展示用」的代码。
- **相邻比较。** 每一份范本都对照同一条任务线上的前一份来写。上一份能做的事继续保留，只加上这一项技能带来的一个新东西，其余尽量逐行不变（下面每一行就是这句差异）。
- **新任务从朴素写法开始。** 后期换新作物（南瓜、迷宫、仙人掌、恐龙、多机）时，先给朴素正确的写法：一圈一圈扫、右手摸墙、冒泡排序、贪心朝苹果走。下一项技能再在它上面改一处。
- **测试兜底。**
  - `test_every_node_has_exemplar` 要求每个节点都有范本。范本在全部解锁时必须能解析、运行 20 秒不出错，并且有农场事件。还要求 4 空格缩进、没有 Tab，并带 `#include <bits/stdc++.h>`、`using namespace std;`、`int main()`。
  - `test_full_playthrough` 要求每一份范本在买到它之前报「尚未解锁」，买到之后能编译并跑出药效。

### 相邻差异

1. harvest → loop：把一次 `harvest()` 包进 `while (true)`。
2. loop → speed：代码不变，只是动作变快，开始空挥（痛）。
3. speed → iff：在 `harvest()` 外加 `if (can_harvest())`。
4. iff → move：每收一格后 `move(East)`。
5. move → forl：用 `for` 走 3 格一圈，再 `move(North)` 换行。
6. forl → till：同样的一圈改成一次性把一行 `till()`。
7. till → plant：先收、不是土就耕，空格 `plant(Bush)`。
8. plant → vars：用 `i == 0` 让第一列留草，其余种灌木。
9. vars → constn：把 3 写成 `const int kSize = 3`。
10. constn → senses：用 `get_pos_x() == 0` 代替计数器判断所在列。
11. senses → ops：改成 `get_pos_x() % 2 == 0`，隔列留草。
12. ops → expand：`kSize` 换成 `get_world_size()`。
13. expand → carrot：奇数列再按 `y % 2` 分成灌木和胡萝卜。
14. carrot → costs：种胡萝卜前先用 `Cost c = get_cost(Carrot)` 看够不够。
15. costs → water：`get_water() < 0.5` 时 `use_item(Water)`。
16. water → tree：灌木换成树。
17. tree → hayup：代码不变，同一套程序每格草收 2。
18. hayup → func：把一格的活提成 `void tendTile()`。
19. func → ref：`tendTile(int& harvested)` 计数，收满 100 次就停。
20. ref → include：`tendTile` 搬进 `farm.hpp`，main 里 `#include "farm.hpp"`。
21. include → sun：新任务向日葵。`stepTo` 加全图扫描，记下最大花瓣的坐标，走过去等熟再收。
22. sun → array：花瓣存进 `int petals[kMax][kMax]`，不再每次重扫。
23. array → rec：坐标打包成 `struct Spot`，`findBest` 返回它。
24. rec → pumpkin：新任务南瓜。一圈补种，整片都熟（`allRipe`）才收。
25. pumpkin → util：回到向日葵，`findBest` 改用 `max()` 先求最大值，再找相等的那株。
26. util → debug：回到南瓜，收完 `quick_print(num_items(Pumpkin))`。
27. debug → timing：`double start = get_time()`，打印每轮用时。
28. timing → autounlock：每轮收完 `unlock(Pumpkins)`。
29. autounlock → fert：回到分文件程序，`farm.hpp` 里种树后 `use_item(Fertilizer)`。
30. fert → maze：新任务迷宫。`turnRight` / `turnLeft` 用 if 链，右手摸墙走到宝藏。
31. maze → swenum：两个转向函数改写成 `switch`。
32. swenum → cactus：新任务仙人掌。`plantAll` 种满，行向东、列向北冒泡排序，再收。
33. cactus → companion：新任务伴侣。种树并按 `get_companion()` 用 `plantHere` 种伴侣作物。
34. companion → dino：新任务恐龙。戴上 `DinosaurHat` 后用贪心 `stepToward` 朝苹果走，走不动就换回 `StrawHat` 结算骨头。
35. dino → debug2：回到仙人掌程序，开头 `set_world_size(3)` 缩小试跑。
36. debug2 → sim：再加一行 `simulate(42)` 固定种子。
37. sim → mega：回到分文件程序，`spawn_drone(farmForever)` 加一架无人机分担。
38. mega → hats：再加一行 `change_hat(TopHat)`。
