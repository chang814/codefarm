# 0.2.4 主线流程与逻辑检查

检查日期：2026-11-11。检查对象为当前桌面 codefarm 源码及 Windows 运行环境。

## 本次怎样通关

执行项目内置的完整玩家路线：从新世界和固定种子 20261111 出发，用真实范本运行、生产资源并按余额购买技能；不调用加资源或直接解锁的测试后门。路线工具在 main 返回后会再次点运行；需要换生产方案时会切回之前的范本。它是程序化通关，不包含真人思考、输入代码和阅读提示的时间，也不是全程用鼠标操作 Godot。

- 完成 45 次购买，覆盖主线解锁项（成本查询随胡萝卜获得）。
- 139 项路线检查通过，总游戏时间 3112.74 秒，约 51.9 分钟。
- 最长购买间隔为结构体约 305.3 秒，其次数组约 255.8 秒、恐龙 240 秒。间隔包含观察与资源准备，不等于纯等待。
- 同一 Windows 路线工具连续运行两次，输出逐行一致。
- C++ 全量测试 1167 项通过。测试读取使用 UTF-8 filesystem 路径，修复此前 Windows 中文绝对路径下的范本读取失败。

## 流程判断

前期“单刀收获 → while → 加速造成空挥 → if 判断成熟 → 移动提高产出 → for 遍历”的因果成立：路线观测到条件判断消除空挥、移动使产出从 1.00 提高到 1.33 干草/秒，for 将覆盖范围从 3 格提高到 9 格。后续混种缓解资源单一、函数复用、数组减少重复测量、结构体携带坐标、多机提高吞吐，主干知识大体递进。

这证明当前推荐路线可完成，不能证明任何购买顺序、任何种子和所有长期运行代码都不会卡住。

## 仍存在的问题与下一步

1. **连续购买缺少消化时间。** 函数、引用、自动解锁、仙人掌等阶段的购买间隔为 0 秒；测试有运行与验证范本，但这不代表新玩家已经理解。建议增加可跳过的小练习与达成提示，先观察试玩再决定是否更改经济或强制门槛。本次没有提高价格或强加限制。
2. **通关路线会主动切回旧的生产代码。** 例如数组与结构体围绕向日葵展开，但下一种技能可能需要胡萝卜。自动路线知道切回混种，新玩家未必知道。建议在技能详情提示缺少的资源、来源及可切回的生产方案。
3. **调试工具在推荐路线中偏晚。** 打印位于南瓜之后才购买；初学者在函数与数组阶段已需要观察变量。建议前置教学中的打印演示，是否调整解锁规则另做平衡验证。
4. **技能连线与真实前置不完全一致。** UI 有向日葵到南瓜的连线，world 的南瓜判定不要求向日葵；迷宫、多机等有多个真实前置，而界面连线并未完整表达，另有 OR 前置。建议未来由模拟器导出带 AND/OR 语义的依赖数据，避免维护两份规则。
5. **迷宫范本不能无限稳定循环。** World 在 300 次宝藏复用后清掉迷宫，而 maze/swenum 范本只在 main 开始调用一次 makeMaze；到上限后 solve 不会重新造迷宫。复用后期还会拆墙形成环，右手法也没有访问记录或超时。主线只需少量宝藏，不影响本次通关，但长挂机应改为有界求解并重建；需要同时处理清场、物质成本与失败重试，不能只移动一行 makeMaze。
6. **进度仍未持久化。** 当前未找到农场、技能和代码的落盘实现。退出程序后保留进度应是后续优先工作。

## 本轮已修复的编辑器问题

- 主编辑器、提示范本和详情窗口不再共用 SyntaxHighlighter 实例，避免高亮器绑定到其他编辑器而丢失主代码配色。
- 固定框架受保护，正文仍可编辑；辅助函数与头文件仍可编写，正文撤销可用。程序加载和范本替换走内部设置文本路径，不受用户编辑保护拦截。
- 报错显示行列、类别与下一步建议；跳到出错行，柔和下划线和气泡保留代码原文。修复 locked_syntax 分类未正确使用解锁提示颜色的问题。
- 冒烟脚本刷新技能详情引用，不再使用已释放的旧实例；无头环境直接跳过截图读取。
