## 0.2.10 — 2026-11-14

### 修复

- 小 bot 不再越点越偏：报错抖动和翻跟头改为始终从静止姿态起算，并取消上一段未完成的动画。此前连续触发会从上一次抖动的中途位置起算，偏移逐次累积。
- 代码区回车被误拦：在 `return 0;` 上一行末尾按回车、在框架行旁输入时，文本差异有两种读法，旧逻辑只取一种，把正常输入当成改动框架而撤销。现在两种读法都触及框架才拦截；紧贴框架行前面输入不再被拒。
- 报错标记每帧刷引擎错误：出错行被改短后，标记仍按旧列号取位置，一次会话可写出数 MB 日志并拖慢编辑。列号现在按当前行长收紧。
- 欢迎页特写被草挡住：镜头与小 bot 之间的草叶和作物在欢迎页收起，点开始后恢复。
- 欢迎页显示存档内容（农场边长、干草、技能数），读到存档一眼可见。

### 画面

- 背景：草甸有柔和色块与缓慢移动的云影，四周有随风摆动的草丛、成簇小花、石子、圆冠树与矮灌木、飘浮的光点和三只蝴蝶。全部由代码按固定种子生成，不带模型或贴图；装饰始终在田块之外，扩田后自动外移。
- 建模：地块改为圆角、圆顶边的柔和方块，法线平滑；阴影更淡、边缘更软。
- 图标：技能树里原先共用「文档 / 移动 / 变量」图标的 23 个技能各有自己的简单图形（帽子、迷宫、时钟、数组格子、分支、骰子等）；提示改为干净的灯泡，视角回正改为准星。

### 验证

- 新增 `verify_0210.gd`，`verify_editor.gd` 增加框架旁输入与过期列号用例。验收脚本一律使用独立存档或关闭存档。
- 模拟器规则、经济、范本均未修改，未重编扩展。

- 移动只花半个动作，所以边走边收比原地收更快，买「移动」划算。

  - 文件级常量对函数和无人机可见。
  - 解锁名不区分大小写。
  - `get_time()` 需要先解锁「计时」。
  - 变量未解锁时把 `for` 的 `i` 写进判断，会给出清楚提示。

## 0.2.1 — 2026-11-11

### 机制

- `simulate(种子)` 真正可执行：解锁「模拟」后用固定种子重放，两次相同种子的生长序列一致。相关测试通过解释器 API 调用，而不是只走内部 `set_seed`。

- 解锁「分文件」后，代码窗口出现简洁的文件栏，可切换或新建已解锁的用户文件（例如 `rows.hpp`），运行时通过 `#include` 接入。未解锁时不会露出空编辑器。

## 0.1.5 — 2026-11-11

按试玩反馈改了运行方式、先痛后药的节奏、视角手感和系统字体，并去掉窗口角落的小色块。

### 运行

- 实心三角是「运行」：把 `main` 完整执行一遍，结束即停；草地仍继续生长。空心三角是「单步」：每次只执行一条语句或一个农场动作，然后暂停。点进代码区仍会停止。不再在 `main` 结束后自动重新执行。

### 解锁与节奏

- 成功收割和失败收割花费相同的完整动作时间；`can_harvest()` 等查询仍是 1 tick。
- 开局一次 `harvest` 约为 1 秒，和草的生长时间相同，所以解锁循环后，`while (true) { harvest(); }` 正好能一刀接一刀收到成熟的草。
- 设置里不再让玩家自己把速度拉满。在「循环」（5 干草）和「条件」之间增加「加速」（8 干草）：买下后动作大约变为 2 倍快，草仍要 1 秒长熟。此时再用纯 `while harvest` 会打在未熟的草上，这就是解锁「条件」（12 干草）的理由。之后仍是移动 20、计数 30、耕地 40、种植 60。

### 相机

- 右键转动 1:1 跟鼠标，不插值滞后。WASD 松开即停。平移是抓住地面拖动的手感，滚轮以鼠标指向为参考缩放。

### 界面

- 系统 UI（顶栏、窗口标题、技能词、说明、设置、日志、气泡）字号加大约 2–4px，并使用 Noto Sans CJK SC（SIL OFL）。代码区仍是 18px 的 JetBrains Mono。
- 窗口右下角缩放手柄改为完全透明的点击区，只用很淡的 L 形线条提示，不再留下半透明金色色块。
